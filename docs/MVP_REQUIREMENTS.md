# ActionTracker MVP 要件定義書

## 1. システム概要

### 1.1 システム名
ActionTracker MVP

### 1.2 システム概要
ActionTracker MVP は、PC 上の行動履歴を収集し、「何にどれだけ時間を使ったか」を可視化するシンプルな行動追跡ツールである。

### 1.3 解決する課題
- 1日の終わりに「今日は何をしたんだろう」と虚無感を感じる
- 集中できた時間がどれくらいか分からない
- 行動を客観的に振り返りたい

## 2. 対象ユーザー

### メインターゲット
- プログラミング学習者
- 個人開発者
- 学生

### ユーザー課題
- 集中できた・できなかった理由が分からない
- 行動を客観的に振り返りたい
- 生産性を改善したい

## 3. システム構成

```
Windows PC
↓
Tracker Agent（Python）
↓
SQLite
↓
FastAPI
↓
React Dashboard
```

### 動作方式
- Windows常駐
- ローカル完結
- オフライン利用可能
- クラウド送信なし

## 4. 画面構成

### 4.1 ダッシュボード
**目的**
現在の作業状況と今日の行動を一目で把握する。

**表示内容**
- 現在利用中サービス
- 今日の利用時間
- 今日の集中時間（開発・学習カテゴリ）
- 今日の娯楽時間（娯楽・SNSカテゴリ）

### 4.2 タイムライン
**目的**
1 日の行動を時系列で振り返る。

**表示内容**
- ガントチャート
- サービス履歴
- カテゴリ色分け

### 4.3 設定
**管理内容**
- カテゴリの追加・編集・削除

## 5. 機能要件

### F-001 行動イベント収集
PC上の行動イベントを収集し、タイムスタンプ・アプリ・サービスを保存する。

**実装状況：** 実装済み

### F-002 ダッシュボード
現在の作業状況、利用時間、集中時間をリアルタイムで表示する。

**実装状況：** 実装済み

### F-003 タイムライン表示
行動履歴をガントチャートで表示する。

**実装状況：** 実装済み

### F-004 カテゴリ管理
カテゴリの追加・編集・削除を行う。

**実装状況：** 実装済み

## 6. UI・UX要件
- ダッシュボードは10秒以内で状況を把握できる構成とする
- タイムラインはカテゴリ別に色分けし、直感的に理解できるようにする
- シンプルで使いやすいインターフェース

## 7. 非機能要件
- ローカル完結
- Windows常駐
- オフライン対応
- プライバシー保護
- シンプルな実装

## 8. 技術構成
- Tracker：Python、pywin32、psutil
- Backend：FastAPI、SQLAlchemy
- Database：SQLite
- Frontend：React、TypeScript、Vite、Tailwind CSS
